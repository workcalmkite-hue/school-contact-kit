# 학교 연락 자동화 도우미 (school-contact-kit)

클로드 코드에게 «말로» 학교 연락 일을 시키기 위한 도우미 파일 모음입니다.
연수 실습 자료의 «한 번에 끝내기» 프롬프트를 붙여넣으면, 클로드가 여기서 필요한 폴더만 받아 설치합니다.

| 폴더 | 하는 일 |
|---|---|
| `hiclass/` | 하이클래스(하이톡) 읽기·보내기 · 출결 연락 자동 답장 |
| `print/` | 말로 프린트 (윈도우) |
| `kakao-windows/` · `kakao-mac/` | 카카오톡 보내기·읽기 |
| `coolmessenger/` | 쿨메신저 보내기·읽기 · 사용량 위젯 |
| `navermail/` | 네이버 메일 MCP |

- 여기 있는 방 이름·학생 명단 파일은 **빈 틀**입니다. 채운 파일은 내 컴퓨터에만 두고 어디에도 올리지 마세요.
- 메시지를 «보내는» 동작은 항상 먼저 보여 드리고, 선생님이 «네»라고 한 뒤에만 보냅니다.
