하이클래스로 온 학부모·학생 출결 연락을 처리한다. 이 폴더(하이클래스)가 열려 있다.
아무것도 묻지 말고 끝까지 처리한다 — 선생님은 자리에 없을 수 있다.

[먼저 읽을 것]
- 출결규칙.txt (답장 문구 · 볼 방 · 답장하지 않을 것) — 「#」 줄은 설명이니 규칙으로 쓰지 않는다
- 우리반.txt (번호 이름) — 「1 김하늘」 「2 이서준」 두 줄만 있으면 아직 안 채운 것이다. 그러면 캘린더·답장 없이 «우리반.txt를 먼저 채워 주세요» 한 줄만 쓰고 끝낸다
- 출결답장_기록.txt 가 있으면 맨 아래 20줄 — 이미 처리한 연락을 또 처리하지 않으려고 본다

[연습 모드]
이 지시문 맨 끝에 «연습»이라는 말이 붙어 오면 연습 모드다.
연습 모드에서는 캘린더에 넣지도, 답장을 보내지도 않는다. «이렇게 하겠습니다»만 정리해서 보여 준다.

[1. 읽기]
- 방 목록:  python talk.py --inbox   (맥은 python3, 윈도우는 python -X utf8)
  --unread 만 보지 않는다. 선생님이 폰으로 먼저 읽으면 «안읽음»이 아니게 된다.
- 「시각」이 «N분전 · N시간전 · 1일전 · 2일전 · 3일전»(최근 3일 — 금요일 저녁에 온 월요일 결석 연락까지 잡으려고)인 방 중에서
  출결규칙.txt [어느 방을 볼까]에 맞는 방만 읽는다:
  python talk.py --read "방 이름 그대로" -n 8
- 처리 대상 = 학부모·학생이 보낸 글 중, 그 뒤로 «나»(보낸이가 "나")의 답장이 없는 것.
  방의 마지막 글이 «나»면 이미 답장한 것이니 건너뛴다.
- 「마지막」 미리보기는 잘린다. 판단은 반드시 --read 로 읽은 전체 글로 한다.

[2. 출결인지 가리기]
출결로 본다: 결석 · 조퇴 · 지각 · 병원 · 열 · 감기 · 장염 · 독감 · 코로나 · 아파서 · 못 갈 · 늦을 · 체험학습 · 경조사
출결이 아니다: 출결규칙.txt [답장하지 않을 것]에 있는 것 — 정리만 한다

분류 (9가지 중 하나):
  하루 이상 못 옴 + 아픔 → 질병결석 / 늦게 옴 + 아픔 → 질병지각 / 중간에 감 + 아픔 → 질병조퇴
  체험학습 · 경조사 → 출석인정결석 (지각·조퇴면 출석인정지각·출석인정조퇴)
  이유 없음 · 늦잠 · 개인 사정 → 미인정 계열 = 넣지 말고 «확인 필요»
  애매하면 넣지 말고 «확인 필요»
날짜: «오늘 · 내일 · 월요일»은 메시지가 온 날 기준으로 실제 날짜(YYYY-MM-DD)로 바꾼다. 며칠이면 시작~끝.
학생: 방 이름(«○○○ 학부모(○○○)»)이나 글에서 학생 이름을 찾고, 우리반.txt 에서 번호를 찾는다. 번호가 없으면 «확인 필요».

[3. 캘린더]
구글 MCP 의 add_attendance 로 넣는다 (분류 · 번호 · 이름 · 시작일 · 끝일 · 메모).
메모에는 이유 한 단어만(«감기», «병원») — 병명·사정을 길게 옮기지 않는다.
넣기 전에 list_attendance 로 그날 같은 학생이 이미 있는지 본다. 있으면 또 넣지 않는다.
«캘린더가 없습니다»가 나오면 make_attendance_calendars 를 한 번 부르고 다시 넣는다.

[4. 답장]
캘린더에 넣은 연락에만 답장한다. 문구는 출결규칙.txt [답장 문구] 그대로.
질병결석·질병지각·질병조퇴·출석인정 계열이면 [서류가 필요할 때 덧붙일 말]을 한 줄 띄우고 덧붙인다.
  python talk.py --room "방 이름 그대로" --msg "답장 문구"
보낸 뒤 결과의 «보냄»이 true 인지 본다. false 면 다시 보내지 말고 «답장 실패 — 직접 확인»으로 남긴다
(실제로는 나갔는데 실패로 읽힌 적이 있다. 두 번 보내면 학부모 화면에 두 번 뜬다).
단체방에 온 출결 연락에는 단체방에 답하지 않는다 — «확인 필요»로 남겨 선생님이 1:1로 답하게 한다.

[5. 기록 · 보고]
출결답장_기록.txt 맨 아래에 이번 처리를 덧붙인다 (지우지 않는다). 한 건에 한 줄:
  2026-11-09 07:50 | ○○○ 학부모(○○○) 07:12 | 질병결석 11/9 | 캘린더 ✓ | 답장 ✓
기록에 이미 있는 연락(같은 방 · 같은 시각)은 다시 처리하지도, 다시 보고하지도 않는다.
처리 대상이 하나도 없으면 «새 출결 연락 없음» 한 줄만 기록하고 끝낸다.
마지막에 화면에도 이렇게 정리한다 (별표·표 없이 이모지와 줄바꿈만):

✅ 출결 처리
■ ○○○ (N번) · 질병결석 11/9 · 캘린더 ✓ · 답장 ✓

❓ 확인 필요
■ ○○○ 어머님 07:00 · 무슨 연락인지 · 왜 애매한지

💬 기타 연락 (답장 안 함)
■ ○○○ 어머님 07:42 · 무슨 내용인지

[하지 않는 것]
- 출결 아닌 연락에 답장하지 않는다
- 학부모 연락처·병명을 기록 파일에 옮겨 적지 않는다
- talk.py 를 고치지 않는다. 막히면 무엇이 막혔는지만 기록하고 끝낸다
